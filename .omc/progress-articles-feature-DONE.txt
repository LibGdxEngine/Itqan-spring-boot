## Learnings
- Backend compile/test needs MAVEN_OPTS="-Xmx2g" (default heap OOMs on compile) + JAVA_HOME=~/.jdks/jdk-21.0.11+10.
- PRE-EXISTING TEST BUG (NOT articles): 6 integration tests call authRepository.deleteAll() in setUp; RefreshToken has @ManyToOne User (FK user_id, no cascade), so leftover refresh tokens from a prior test method tripped a refresh_tokens->users FK violation. FIXED centrally + test-only in BaseIntegrationTest via @AfterEach refreshTokenRepository.deleteAll() (no production change, no assertions weakened). This is what turned 22 errors -> 0.
- Backend files all created & reviewed: Article entity/repo/service/controller, dto x4, mapper, V14 migration, ArticleServiceTest (3 tests), ErrorCode.ARTICLE_NOT_FOUND, SecurityConfig permitAll /api/articles[/**], landing integration (config featuredArticleIds, LandingArticleDto, response+request fields, service hydrateArticles published-only).
- Slug is unicode-aware (Arabic ok); reading time = max(1, ceil(len/1000)). Controller route precedence: literal /search,/mine,/id/{id} resolve before /{slug} (Spring).
