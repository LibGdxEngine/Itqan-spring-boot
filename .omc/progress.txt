## Learnings
- npm run lint exits 0 but reports 1289 PRE-EXISTING errors (only in src/app/[locale]/video-demo + VideoPlayer.tsx + generated lib warnings) — none in our files; gate on per-file eslint instead.
- OG IMAGE / SATORI PITFALLS (route was crashing in prod BEFORE this task — 'failed to pipe response'):
  1. satori cannot parse full Arabic font TTFs (Noto Kufi/Noto Sans Arabic/Amiri all throw 'lookupType: 5 - substFormat: 3'). Working families as Google subsets: IBM Plex Sans Arabic, Cairo, Tajawal.
  2. Google css2 'text=' subsets are served as woff2 to ANY browser UA (satori can't read woff2). UA-LESS request => format('truetype'). Magic 00010000 verified.
  3. satori has NO bidi: dir attr and CSS direction are ignored; multi-word Arabic renders in reversed word order. Fix: rtlWords() pre-reverse + whiteSpace:nowrap + short single-line copy (wrap would scramble order).
  4. Render errors surface when the Response STREAMS, after headers — consume via image.arrayBuffer() inside try/catch (renderToPng) to enable per-family fallback, final fallback = Latin-only card (bundled default font).
  5. Module-level fontCache Map: 1.3s cold -> 0.48s warm.
- next-server renames its process title ('next-server (v1...)') so pkill -f standalone/server.js NEVER matches — use fuser -k PORT/tcp. Also pkill -f self-matches the Claude bash wrapper (exit 144) — use [b]racket patterns.
- Standalone smoke test recipe: npm run build; cp -r public .next/standalone/; cp -r .next/static .next/standalone/.next/; PORT=X node .next/standalone/server.js. Backend down => articles fetch fails gracefully (empty JSON-LD list, fallback metadata w/ noindex) as designed.
- Tailwind v4 logical utilities (ms-/ps-/start-) used throughout; CourseCard stagger lives in the parent motion grid (courses/page.tsx), not the card file.
